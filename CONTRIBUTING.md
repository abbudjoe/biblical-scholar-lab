# Contributing

Contributions are welcome only through reviewed pull requests that follow `AGENTS.md`, activation scope, benchmark/source authority, and repository governance.

All commits must include a Developer Certificate of Origin sign-off:

```text
Signed-off-by: Your Name <you@example.com>
```

By signing off, the contributor certifies the Developer Certificate of Origin 1.1: <https://developercertificate.org/>

Do not submit restricted source text, private benchmark material, user data, credentials, or unapproved model-generated scholarly gold.
